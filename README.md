\# Blue BookStore



Blue BookStore adalah aplikasi web toko buku.



\## Teknologi

\- PHP

\- MySQL

\- HTML

\- CSS

\- JavaScript



\## Fitur Aplikasi

\- Pengelolaan buku

\- Pengelolaan penulis

\- Keranjang belanja

\- Checkout

\- Transaksi dan invoice

\- Pengelolaan admin dan customer



\## Menjalankan Aplikasi

1\. Jalankan Apache dan MySQL melalui XAMPP.

2\. Letakkan folder proyek di direktori htdocs.

3\. Import database melalui file database.sql menggunakan phpMyAdmin.

4\. Sesuaikan konfigurasi database pada koneksi.php.

5\. Buka aplikasi melalui browser menggunakan localhost.
